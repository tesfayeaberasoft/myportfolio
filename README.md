## 📋 Overview

A modern, responsive portfolio website showcasing my work as a Full-Stack Developer and Software Engineering student at Wachemo University. This portfolio features a clean design with dark/light mode toggle, smooth animations, and a fully functional contact form with database integration.

## ✨ Features

### 🎨 Design & UI
- **Dark/Light Mode Toggle** - Persistent theme preference using localStorage
- **Fully Responsive Design** - Mobile-first approach, works on all devices from 320px to 4K
- **Smooth Animations** - Fade-in scroll effects, hover animations, and scroll progress indicator
- **Modern Card Layout** - Clean, glassmorphic design with backdrop blur effects
- **Interactive Elements** - Animated profile picture with pulse effect, project hover overlays
- **Custom Scrollbar** - Styled scrollbar matching the theme
- **Sticky Navigation** - Blur effect navigation bar with smooth scroll
- **Back to Top Button** - Appears after scrolling 500px
- **Mobile Hamburger Menu** - Collapsible menu for mobile devices
- **Preloader Animation** - Smooth loading experience

### 📝 Contact Form Features
- **Real-time Validation** - Instant feedback for name, email, and message fields
- **AJAX Form Submission** - No page reload, smooth user experience
- **MySQL Database Integration** - Stores all contact messages securely
- **Visual Response Messages** - Success/error messages displayed in HTML (not alerts)
- **Input Sanitization** - Protection against XSS and SQL injection
- **Email Format Validation** - Both client and server-side validation
- **Character Limits** - Name (2-50 chars), Message (10-1000 chars)

### 📱 Content Sections
- **Hero Section** - Introduction with profile image and CTA buttons
- **About Me** - Personal bio, education, and location
- **Tech Stack & Tools** - Frontend, Backend, and Development Tools cards
- **Featured Projects** - 3 showcase projects with hover overlays
- **Contact Section** - Contact info card and validated contact form
- **Footer** - Social links, navigation, and copyright

### ⚡ Technical Features
- **Scroll Progress Bar** - Visual indicator of page scroll position
- **Intersection Observer API** - Fade-in animations on scroll
- **localStorage** - Theme preference persistence
- **FormData API** - Modern form handling
- **Fetch API** - Asynchronous form submission
- **CSS Custom Properties** - Dynamic theme switching
- **CSS Grid & Flexbox** - Modern layout techniques
- **Backdrop Filter** - Frosted glass effects
